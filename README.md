VinkCrypt — это легкий и быстрый инструмент для шифрования файлов на Python, использующий побитовое XOR-шифрование.
🛡️ Как это работает?
Программа преобразует содержимое любого файла (текст, изображения, видео) в нечитаемый набор байтов и изменяет расширение файла на .vinks. Без знания секретного ключа восстановить исходные данные невозможно.
✨ Особенности:
Поддержка любых типов файлов (.txt, .jpg, .mp4 и др.).
Мгновенное шифрование и дешифрование.
Простой интерфейс командной строки.
Идеально подходит для изучения основ криптографии и работы с бинарными данными в Python.
